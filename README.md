A playful delete button where the bin icon chomps and swallows the label on click. Pure HTML, CSS & JavaScript.

---

## ✨ Features

- 🗑️ Bin chomps and swallows the text label
- 🎭 Playful CSS clip-path animation
- ✨ Satisfying interaction feedback
- ♿ Accessible button semantics
- ⚡ Zero dependencies
